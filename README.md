The Campus Canteen Pre-Order and Queue Management System is a DBMS-based application that lets students pre-order food from the canteen, track their order status in real time, and avoid long lunch-hour queues, while giving canteen staff a live dashboard to manage the order queue and admins tools to manage the menu, pricing, and stock. The backend uses a normalized PostgreSQL database with tables for Students, MenuItems, Orders, OrderItems, OrderStatusLog, and KitchenCapacity, along with a trigger that automatically logs every order status change, a stored procedure that estimates waiting time based on kitchen capacity and pending orders, and transaction-safe order placement that rolls back if stock runs out mid-order. The frontend is a role-based interface (Student, Staff, Admin) built with HTML, CSS, and Bootstrap, with a login page and dashboards for each role.
